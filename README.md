# NoNap

A production-ready, real-time driver drowsiness detection mobile application.

## Directory Structure

- `app/`: React Native / Expo application
- `backend/`: Python inference server (YOLOv8 + ViT)
- `website/`: Promotional website (Next.js)
- `docs/`: Documentation
- `scripts/`: Useful scripts for setup and running

## Quick Start

1. **Setup**: Run `./scripts/setup.sh` to install all dependencies.
2. **Run**: Run `./scripts/start_dev.sh` to launch the backend, app, and website simultaneously.
